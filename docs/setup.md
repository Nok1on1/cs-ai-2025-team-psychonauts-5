# Setup Instructions – Dialogos

Welcome to the Dialogos project! This guide will help you get the development environment running locally on your machine.

## 📦 Requirements

- Node.js (v18+)
- npm (v9+) or yarn
- Git
- MSSQL Server (for local DB development)
- An OpenAI or Gemini API key (see `.env.example`)

## 🧾 Clone the Repository

```bash
git clone https://github.com/Nok1on1/cs-ai-2025-team-psychonauts-5.git
cd cs-ai-2025-team-psychonauts-5


# Using npm
npm install

# OR using yarn
yarn install

# Start development server
npm run dev
